# One-Shot
Dear space explorer, you are on a space journey far away from your home planet. Somehow, an interstellar pest has invaded all ten rooms of your spaceship. You only have ten bullets to clean up the alien pests so you need to use only one bullet per room. Keep zapping and best of luck!

# Controls
Reminder, you only have one bullet. Simply drag your mouse or finger back to shoot! Make sure you aim well.
